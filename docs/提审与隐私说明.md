# 慧礼记 — 提审与隐私配置说明

## 一、提审建议

**服务类目**：工具 > 记账（或 工具 > 备忘录）。不要选金融、支付类类目。

**版本描述（可直接粘贴）**

> 慧礼记是一款礼金记账工具，帮助用户记录婚礼、寿宴、满月、乔迁、白事等场合的礼尚往来，生成电子礼簿、回执和往来统计，方便日后查询与回礼。
> 小程序本身不提供任何支付、收款或资金托管功能：宾客在小程序内只登记姓名与礼金金额，实际转账由宾客使用微信「扫一扫」向主家本人的微信收款码完成，资金直接进入主家本人的微信零钱，小程序不经手、不留存任何资金。主家确认收到后，系统才把该笔礼金记入礼簿。

**审核备注（填写在"补充说明"）**

> 1. 测试路径：「我的」登录 →「主家信息」上传任意收款码图片 →「礼簿管理」新建礼簿 →「模拟宾客随礼」登记一笔 →「我的」待确认礼金点「确认收到」→ 查看电子回执、礼簿统计、往来、导出。
> 2. 收款码为主家本人上传的个人微信收款码，仅在主家自己的礼簿页面向其宾客展示，用于宾客自愿转账随礼；小程序不发起支付、不代收款、不分账。
> 3. 蓝牙权限仅用于连接主家自备的热敏打印机打印礼金回执。

**可能被问到的问题**

| 问题 | 回答要点 |
|---|---|
| 是否涉及资金交易 | 否，小程序只做登记；转账在微信内由用户自行完成 |
| 是否诱导转账 | 否，转账对象为主家本人，金额由宾客自行决定，可不转账直接取消 |
| 收款码来源 | 主家本人上传，仅主家本人礼簿使用 |

若仍被拒，长期方案为接入微信支付商户号（技术文档 §6.4 方案 A），由微信支付回调确认到账。

## 二、用户隐私保护指引（小程序后台 → 设置 → 服务内容声明 → 用户隐私保护指引）

需勾选并填写用途：

| 信息类型 | 用途说明（可直接粘贴） |
|---|---|
| 微信昵称、头像 | 用于主家登录后显示个人信息 |
| 选中的照片或视频信息 | 用于主家上传本人微信收款码图片 |
| 相册（仅写入）权限 | 用于保存礼簿码、礼簿台卡、电子回执到手机相册 |
| 蓝牙 | 用于连接热敏打印机打印礼金回执 |
| 摄像头 | 用于扫描礼簿码、收款码（wx.scanCode），不保存画面 |
| 剪切板（写入） | 用于点「复制」时写入礼簿编号、对账文字，不读取剪切板内容 |
| 头像上传 | 头像上传到微信云存储，用于在账号与相关礼簿中显示（v3.67.2 起） |
| 用户输入的信息（姓名、金额、关系、祝福语） | 用于生成礼簿、电子回执和人情往来统计，仅主家与宾客本人可见 |

**小票二维码与认领（v3.57.0 起，v3.58.0 改为小程序码）**：热敏小票底部可打印一个小程序码（v3.59.0 起默认关闭，主家在打印设置里自行打开），用微信扫码打开这一笔随礼的电子回执。
- 小程序码里只有 `t=` 加一个 12 位随机字符串（不含姓名、金额等内容），指向「电子回执」页；小程序码永久有效，任何人扫到都能打开这一笔回执（姓名、关系、金额、备注、主家称呼），不含其他礼金或礼簿信息。主家可在「礼簿 → 更多 → 重置二维码」换掉随机字符串，旧小票上的码立即失效。
- 为加快补打，云端会把小程序码图片转成打印数据，按这笔记录缓存到云存储（`rcptqr/` 目录，仅云函数可访问，文件里只有黑白点阵）；缓存按小程序版本（正式版 / 体验版）区分，每条记录只留一份；重置二维码时删除旧缓存，主家清除数据时一并删除。
- 礼台代为登记的记录没有宾客的微信身份。宾客扫码后可点「放入我的随礼记录」认领：仅在这笔记录无人认领时有效，先认先得，只记录认领人的微信标识用于在其「我的随礼记录」中显示，不改动主家的账目；主家可「解除认领」。宾客清除自己的数据时，其认领会被解除（记录属于主家，不删除）。
- 隐私指引「用户输入的信息」用途可补充：「用于生成电子回执及小票小程序码，扫码查看回执与放入我的随礼记录」。无需新增权限类别。

**内容安全（v3.71.0 起）**：用户填写、会展示给他人的文字与图片，在云端提交时调用微信官方内容安全接口检测，违规内容提示「内容含有不适宜信息，请修改后再提交」，不保存、不展示。
- 文字（`security.msgSecCheck` v2）：礼簿名、礼簿地点、主家称呼、机构名称、本场主家称呼、记账人姓名、回执标题 / 落款 / 页脚、小票标题 / 致谢语 / 页脚、微信昵称、宾客填写的姓名 / 备注 / 区分备注，以及礼台录入的随礼人姓名 / 备注。仅本人可见的往来记录不送审。
- 图片（`security.imgSecCheck`）：收款码图片、本场收款码、头像；超过 1MB 的图片接口不支持，跳过检测。
- 送审内容只用于检测，开发者不另行保存；检测服务异常、超时或未开通权限时不阻断用户操作。
- 提审说明可补充：「小程序对用户输入的文字与图片接入微信内容安全接口」。无需新增隐私权限类别。

**订阅消息（微信服务通知）**：均为一次性订阅，用户点「允许」才发送，每次允许只发一条，不用于营销。
- 新礼金提醒（给主家 / 记账人）：宾客点「我已完成转账」后提醒核对确认；模板 ID 见 `miniprogram/config.js` 的 `NOTIFY_TMPL_ID`。**v3.66.3 起默认关闭**，主家 / 记账人在「我的 → 高级功能 → 新礼金微信提醒」自行开启（开启时才弹订阅授权），未开启的人不会弹授权、不会收到提醒。
- 入簿通知（给宾客，v3.66.1）：宾客在随礼时（「我已完成转账」或现金「确认随礼」）允许后，主家确认收到时发一条，内容为主家称呼与事由、金额、记账时间、支付方式、备注，点开查看这一笔的电子回执；礼台代为登记的宾客没有微信身份，不发送。模板 ID 见 `GUEST_NOTIFY_TMPL_ID`。
- 亲友办事提醒：用户自己设置提醒时允许，到期提醒；模板 ID 见 `REMIND_TMPL_ID`。
- 小程序内「隐私与数据」页有对应的「微信服务通知」一节，改这里时同步修改 `pages/privacy/privacy.js`。

**联系客服与反馈**：用户主动联系客服、提交反馈时提供的信息（文字、截图及微信自带的机型 / 版本信息）由微信客服 / 反馈通道处理，开发者仅用于答复和定位问题，小程序自身不另行收集。

**数据保存与删除**：数据存储于微信云开发；导出文件在下载后立即从云端删除，未下载的导出文件 24 小时内自动清理；主家可在「我的 → 隐私与数据 → 清除我的全部数据」永久删除全部数据。宾客在他人礼簿中的随礼记录属于主家礼簿档案，如需删除请联系主家作废。

**小程序内的隐私说明**：「我的 → 隐私与数据」页（v3.52.0 起，原为弹窗）完整展示：保存的信息、可见范围、导出文件与存档 PDF 的保留、回收站 15 天（会员可选 30 / 60 天）、设备权限（相册写入 / 蓝牙 / 选图 / 摄像头扫码 / 剪贴板）、头像与内容安全检测（v3.71.1 补充）、客服与反馈；未登录也可查看。登录后页面下方为「我的数据」：导出与备份入口、清除我的全部数据。正文与上文保持一致，改隐私指引时同步修改 `pages/privacy/privacy.js` 的 `SECTIONS`。

## 三、需在云开发控制台手动完成的配置

1. **数据库索引**（云开发控制台 → 数据库 → 选中集合 → 索引管理 → 添加索引；全部选"非唯一"）：

   | 集合 | 索引名 | 索引字段（按顺序） | 用途 |
   |---|---|---|---|
   | records | owner_status_time | ownerOpenid 升序, status 升序, createdAt 降序 | 待确认、礼簿列表 |
   | records | owner_day_status | ownerOpenid 升序, payDay 升序, status 升序 | 今日收礼、按日筛选 |
   | records | owner_book_status | ownerOpenid 升序, bookId 升序, status 升序 | 按礼簿列表、统计、导出 |
   | records | owner_book_time | ownerOpenid 升序, bookId 升序, createdAt 降序 | 礼簿页按礼簿筛选 |
   | records | owner_book_amount | ownerOpenid 升序, bookId 升序, amount 降序 | 礼簿页按礼簿 + 金额排序 |
   | records | payer_status_paid | payerOpenid 升序, status 升序, paidAt 降序 | 宾客随礼记录、送出的礼 |
   | records | payer_time | payerOpenid 升序, createdAt 降序 | 宾客防刷 |
   | records | claimed_status_paid | claimedOpenid 升序, status 升序, paidAt 降序 | 我的随礼记录（小票二维码认领的）|
   | records | rcpt_token | rcptToken 升序 | 扫小票二维码按 token 查回执 |
   | records | batch | batchId 升序 | 批次录入 |
   | members | member | memberOpenid 升序 | 身份解析 |
   | members | aid | aid 升序 | 记账人列表、新礼金提醒 |
   | accounts | owner | ownerOpenid 升序 | 身份解析 |
   | users | openid | openid 升序 | 登录、身份解析 |
   | books | owner_time | ownerOpenid 升序, createdAt 降序 | 礼簿列表 |
   | gifts_out | owner_name | ownerOpenid 升序, toName 升序 | 人情往来 |
   | gifts_out | owner_date | ownerOpenid 升序, date 降序 | 人情往来 |
   | exports | owner_file | ownerOpenid 升序, fileID 升序 | 导出文件清理 |
   | exports | keep_time | keep 升序, createdAt 升序 | 定时清理 |

2. **定时触发器**（命令行部署不会上传触发器，需在开发者工具里逐个右键 `cloudfunctions/<函数名>/config.json` →「上传触发器」）：
   - export：每天 3:00 删除超过 24 小时未下载的导出文件。
   - login、account、records、payment、books：每 5 分钟预热一次，保持实例常驻、减少冷启动（每个函数每天约 288 次调用，直接返回不读写数据库）。

2.1 **小程序码生成（v3.58.0）**：两条通道，任一可用即可。① payment 云函数的云调用权限 `wxacode.getUnlimited`（命令行部署不一定应用 `config.json`，开发者工具「上传并部署」有时报「指定的 functionname 已存在」）；② system 云函数环境变量 `WX_APPSECRET`（与「一键建索引」共用，用 AppSecret 走 HTTPS 接口，**推荐确认已配置**）。配置后到「我的 → 回执样式 → 打印小票」点「检测小程序码生成」验证。payment 依赖 pngjs、jpeg-js，命令行部署带 `--r` 会在云端安装。

3. **云函数超时时间（必做）**：命令行部署不会应用超时设置，所有云函数默认 3 秒。云开发控制台 → 云函数 → 选中函数 → 版本与配置 → 编辑：export 60 秒；renqing、books 20 秒；其余 10 秒。export 不调高会导致 PDF / Excel 生成超时打不开。

4. **数据库权限**：所有集合设为「所有用户不可读写」，前端只通过云函数访问（云函数另外忽略带 _openid 的客户端伪造文档）。
